# DivaSkin – Shopify Skincare Store

DivaSkin is a demo skincare ecommerce store created using Shopify.

## Features
- Hero banner with promotional announcement
- Product catalog with skincare products
- Navigation menu (Home, Shop, Contact, Best Sellers, FAQ, About Us)
- Featured products section
- Customer testimonials
- Trust badges (Natural Ingredients, Dermatologist Tested, Secure Payments)
- Professional footer with quick links and customer support
- Email subscription section
